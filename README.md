# CoinRift Privacy Policy

Public Turkish and English privacy policy for CoinRift.

## GitHub Pages

After pushing the repository to GitHub:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder.
4. Save and wait for the public URL to become available.

Expected URL:

`https://sofiman25.github.io/coinrift-privacy/`

The page contains no analytics, cookies, external fonts, or JavaScript.
